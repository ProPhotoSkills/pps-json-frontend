# HTML-Seiten mit CSS und Footer anzeigen

## Umsetzung
- Ange­klickte HTML-Dateien weiterhin vollständig im Redaktionssystem öffnen.
- Das hochgeladene PPS-Seiten-CSS in jede HTML-Vorschau einfügen, damit die Seite korrekt gestaltet erscheint.
- Den aktuell ausgewählten Footer aus dem Footer-Ordner unter der HTML-Seite ergänzen.
- Bereits vorhandene Seitenelemente erhalten; einen vorhandenen Footer nicht doppelt anzeigen.
- Die Quelltext-Ansicht zeigt weiterhin unverändert die originale Repo-Datei.

## Prüfung
- Build prüfen.
- Eine HTML-Datei im Browser öffnen und kontrollieren, dass Gestaltung und Footer sichtbar sind.
